# 回归用例目录

在界面中「更多 → 保存为回归用例」会在这里创建 `<用例编号>/` 目录（来源文件、模板工作副本、规则、映射与期望结果）。
`python scripts/regression.py` 与 pytest 会运行这里的全部用例。

**只保存合成测试数据或已脱敏的文件。** 提交前请确认目录中没有真实个人信息。

## 目录中的用例

| 用例 | 类型 | 用途 |
|---|---|---|
| `20260923-085124-3d8d48` 合成种子：订单分组 + 重复明细（XLSX） | **合成测试数据** | 让 `regression/` 的「已提交用例」链路真正在 CI 中运行（此前目录为空，`test_committed_cases_still_pass` 被跳过，该路径等于没有覆盖）。15 条样本，覆盖每组一份 + 重复明细行 |

**合成种子不等于真实业务验收。** 它证明的是回归机制本身可用：用例能从磁盘加载、重放、并逐字段比对期望值
（实测把期望值改成别的内容后 `run()` 返回 `ok=False` 并给出
`字段「订单号」：保存时 "…" → 现在 "DD-014"`）。真实业务验收仍待用户提供脱敏样本，见
`docs/quality/verification.md` 的「仍需用户材料」一节。
