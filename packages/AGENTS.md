# 共享包（`packages/`）

**先读仓库根目录的 `AGENTS.md`。** 这里只有一条额外的规则，但它是最容易被破坏的一条：

> **共享包不得导入任何应用或服务。**

`synwevo_core` 里出现一行 `import synwevo_docs`，账户服务就再也不能在没有文档引擎的机器上启动；
`packages/ui` 里出现一个只有 Synwevo Docs 用得上的组件，另外两个外壳就开始为它构建体积买单。

| 包 | 归属 | 判断标准 |
|---|---|---|
| `platform-core` | 唯一的持久化入口、租户上下文、身份与会话、口令、机器身份、OIDC 令牌存储、HTTP 骨架 | 身份服务**和**业务应用都要用 |
| `auth-client`（`python/` 与 `web/`） | 应用接入统一身份：OIDC 依赖方、共用会话路由、浏览器端会话上下文与平台导航 | 每个依赖方都要做同样的事，且做错一次就是一个安全问题 |
| `ui` | 设计变量、主题、Toast/对话框、尺寸适配 | 三个外壳都在用 |

**新增共享代码之前先问一句：现在有几个模块用它？** 只有一个的话，它属于那个模块。
「将来可能会共用」不是理由——把它搬回去的成本远低于把一个万能 `common` 拆开的成本。

`packages/contracts` 目前不存在，这是有意的：现在没有哪一组类型是三方共用而又不属于
`synwevo_core` 的。需要时再建，不要先建一个空目录占位。
