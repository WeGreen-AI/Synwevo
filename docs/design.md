# 设计记录：视觉、交互与动效

本文记录 DocWeave 工作台的设计依据、规范与验证方式。内容对应实际代码（`frontend/src/styles.css`、
`frontend/src/components/`、`frontend/src/views/`），不是设计提案。

---

## 1. 现有体验审查（升级前）

在真实项目上走查上传 → 模板 → 字段 → 映射 → 样本 → 预览 → 生成 → 下载，记录到的问题：

| 问题 | 具体表现 | 影响 | 处理 |
|---|---|---|---|
| 批量操作缺失 | 映射只能逐条点「禁用」「✕」，每条都要确认 | 10 条映射全部禁用 = 10 次点击 + 10 次确认 | 列表多选 + 批量条（DW-044） |
| 没有键盘路径 | 除撤销/重做与 Esc 外，主工作流全靠鼠标 | 无法快速在映射间移动核对 | 列表键盘导航 + 命令面板（DW-044） |
| 文档区被挤压 | 1280×800 下两侧面板占 43% | 核心内容只剩 57% | 右侧面板可拖拽 + 响应式默认宽度（DW-043） |
| 布局不被记住 | 只有左栏宽度持久化 | 每次重开都要重新调整 | 统一 `remember/recall`（DW-046） |
| 主题不完整 | 12 处硬编码浅色 | 深色下徽章、步骤条、选择栏发白 | 全部令牌化（DW-045） |
| 大表翻页卡顿 | 每页 400–650 ms | 滚动大表明显停顿 | 复用已解析工作簿（DW-040） |

审查覆盖了长文件（20000 行 × 30 列合成表）、密集表格、长字段名、错误状态（定位失效、OCR 低置信度、
部分失败任务），不只是空白首页。

| [n8n：UI mapper](https://docs.n8n.io/build/work-with-data/reference-data/use-the-ui-mapper) | 从来源数据建立可复用引用，而不是复制当前值 | 选中示例行的单元格后，规则指向「该列」而非该单元格的值 | `locator` 提案带「随样本变化 / 固定」标签；`variesText()` 在每条映射上显示 |
| [n8n：运行记录](https://docs.n8n.io/build/understand-workflows/understand-executions/view-executions-for-a-single-workflow) | 区分「运行记录」与「配置版本」 | 重试默认复用原快照；改模板或规则要新建关联任务 | `job_runs` 运行记录 + 任务快照，见 `docs/integration/api.md` |

## 3. 设计令牌

全部定义在 `frontend/src/styles.css` 的 `:root`，深色主题只重定义令牌值。

* **表面**：`--bg` `--panel` `--panel-2` `--surface` `--surface-hover` `--surface-active` `--overlay`
* **线与文字**：`--line` `--line-strong` `--text` `--text-2` `--muted`
* **强调与状态**：`--accent` `--accent-strong` `--accent-weak` `--accent-line`、`--ok(-weak)` `--warn(-weak)` `--err(-weak/-line)`、`--block`
* **纸张（不随主题变化）**：`--paper` `--paper-text` `--paper-line`
* **间距**：`--sp-1..5` = 4 / 8 / 12 / 16 / 24 px
* **圆角**：`--radius-sm` 6、`--radius` 8、`--radius-lg` 12
* **高度**：`--shadow`（卡片）、`--shadow-lg`（浮层）、`--focus`（焦点环）
* **字体**：`--font`（系统中文字体优先）、`--mono`
* **动效**：`--dur-1` 110 ms（短反馈）、`--dur-2` 180 ms（面板过渡）、`--dur-3` 300 ms（较大布局变化）、`--ease` `cubic-bezier(.2,.8,.2,1)`

状态覆盖：普通、`:hover`、`:focus-visible`、选中（`.on` / `aria-selected`）、禁用（`:disabled` / `.off`）、
加载（`.empty`、骨架文案）、错误（`.notice.err`、字段级红色说明）。

### 主题与文档的边界

界面主题只作用于「外壳」。文档页面、网格单元格、PDF 页、幻灯片一律使用 `--paper*` 令牌：

```css
.doc-page, .editor-page, .pdf-page, .sheet, .grid, .tline, .slide-page {
  background: var(--paper); color: var(--paper-text);
}
```

深色下实测：`.topbar` = `rgb(22,28,37)`，而 `.gcell` / `.doc-page` 仍为 `rgb(255,255,255)` / `rgb(17,20,24)`。
主题不会写入生成的文件，也不改变导出颜色。

## 4. 布局

* 三段式：左侧文件列表（可折叠）→ 来源文档 ↔ 目标模板双栏 → 右侧映射/字段/样本/校验面板（可折叠、可拖拽调宽）。
* 「左来源、右模板」关系固定，中间连线跟随滚动与缩放。
* 双栏分隔条与右侧面板分隔条都可拖拽；拖拽时在 `body` 上加 `resizing` 类，避免产生选中文字。
* 宽度、折叠状态、缩放、连线开关、当前页签均记住（`localStorage`，不可用时静默降级）。
* 响应式：`≤1500px` 与 `≤1200px` 收紧两侧默认宽度；手机屏显示明确提示并保留任务查看与下载入口。

## 5. 操作与状态

* **联动高亮**：来源选区、目标字段、映射三者互相定位。颜色之外同时有编号（`#3`）、名称（「字段『客户名称』」）和焦点提示，不只靠颜色。
* **多选规则**：游标移动与选中分离；`X` 切换、`Shift` 范围、`⌘/Ctrl` 点击追加、`⌘A` 全选、`Esc` 取消。批量操作走与单条相同的事务保存，因此一次撤销即可整体回滚。
* **中文输入法**：所有全局按键处理先检查 `isComposing` / `keyCode === 229`；命令面板内部同样检查。输入框、文本域与可编辑区域内不触发字母快捷键。
* **浏览器冲突**：只接管 `⌘K`（命令面板）与 `⌘F`（在解析后的文件里查找，而不是浏览器查找可见文本 —— 大表只渲染 145 个单元格，浏览器查找会漏）。不接管 `⌘S`/`⌘P`/`⌘W`/`⌘T`。
* **保存状态**：顶部常驻「已自动保存 / 保存中 / 保存失败」。4xx 业务校验失败不显示为保存失败，而是在相应位置说明原因。
* **错误呈现**：定位失败显示在对应映射条目上并给出「在此文件中重新定位」；逐文件校验页签汇总问题并可逐项跳转；批量错误用汇总 + 逐项定位，不刷 Toast。

## 6. 动效

| 场景 | 时长 | 属性 |
|---|---|---|
| 按钮/条目反馈、勾选框出现 | `--dur-1` | `background` `opacity` |
| 命令面板、批量条出现 | `--dur-2` | `transform` `opacity` |
| 面板折叠/展开、布局变化 | `--dur-3` | `transform` `width` |
| 拖拽分隔条、调整缩放 | 无过渡 | 直接跟手 |

* 选区、连线与坐标计算不参与过渡：缩放和滚动期间坐标必须准确，动画只作用于外壳。
* 虚拟列表只渲染视口内节点（20000×30 表格实测 145 个单元格节点），不给每个单元格挂动画或监听器。
* `@media (prefers-reduced-motion: reduce)` 将三个时长令牌置 0 并把所有动画/过渡压到 1 ms；键盘可完成同样的操作。

## 7. 可访问性

* 焦点：`:focus-visible` 统一描边；映射列表本身可聚焦（`tabindex=0`），点击条目后立即可用键盘。
* 语义：映射列表 `role="listbox"` + `aria-multiselectable`，条目 `role="option"` + `aria-selected`；批量条 `role="toolbar"`；命令面板 `role="dialog"` + `role="listbox"`；菜单 `role="menu"`。
* 非颜色提示：选中有勾选标记，禁用有「已禁用」徽章，错误有文字说明与图标。
* 快捷键说明：`?` 打开完整键位表（`frontend/src/components/Shortcuts.tsx`）。

## 8. 动效与性能的实测结果

在可见的 Chrome 窗口中用真实帧计时测量（`scripts/ui_perf.py`；隐藏或无头窗口会把 `requestAnimationFrame` 节流，测到的是节流值）。本机显示器空闲节拍中位 8.3 ms（约 120 Hz）：

| 场景 | 帧间隔 |
|---|---|
| 滚动 20000×30 的大表 | 中位 8.3 ms，p95 9.7，最大 16.6（掉一帧） |
| 拖拽面板分隔条 | 中位 8.3 ms，p95 8.6，最大 10.2（未掉帧） |
| 长任务（>50 ms） | 0 个 |

即动效与虚拟列表都跟得上屏幕刷新节奏。完整数据与方法见 `docs/quality/verification.md` 第 11 节。

## 9. 待继续的事项

* 帧时间只在本机 120 Hz 屏上测过；60 Hz 或更低配置的机器未测。
* 小屏（<768px）目前是「查看 + 任务下载」定位，映射建立仍建议在桌面完成；移动端编辑能力未做，也未在文档中声称支持。
