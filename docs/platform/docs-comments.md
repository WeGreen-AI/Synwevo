# 项目评论与提及（CI-33）

9.8「有上下文的协作」：项目上的评论、提及与待解决事项，和通知联动；锚点绑定版本，原内容变了要提示失效，不能悄悄跳到错误字段。

## 1. 决策记录

| 项目 | 结论 |
|---|---|
| 问题与基线 | Docs 里没有任何评论/提及能力：关于某个字段该取哪一列的讨论只能在群聊里说「第三个字段」，链接卡片（CI-31）能指到项目，指不到字段；也没有「待解决」的概念。 |
| 成熟参考 | Notion 帮助中心「Comments, mentions & reminders」（2026-09-26 读取）：页面级与行内两种评论、`@` 实时搜索成员、被提及者收到收件箱通知、**对无权访问页面的人提及不会通知**、可解决/重开、作者可编辑删除；Linear「Comment on issues」（读取同日）：线程回复、`…` 菜单编辑/删除、线程可标记解决。二者都没有写明锚定内容变化后怎样处理——本项目按 9.8 的要求自定：锚点在读取时重新判断。 |
| 对比与选择 | (a) 复用群聊承载项目讨论：讨论会散落、无法定位到对象、也无「已解决」；(b) 富文本行内批注（像 Google Docs 那样锚在文字范围上）：本项目的对象是字段/映射/文件/任务，不是自由文本，锚在**对象 id + 当时版本**上更准确也更稳；(c) **本方案**：一级评论 + 一层回复，锚点四种对象或整个项目，读取时按当前模板版本/字段/映射/文件判断有效，`@` 只允许工作空间成员，通知分「被提及」与「参与者」两种。保留：Docs 现有对象授权（authz 路由策略）、通知目录与收件箱、账户服务不导入 Docs 代码。 |
| 预期变化 | 项目页「更多 → 评论…」（命令面板同）打开抽屉：未解决在前，一级/回复，锚点按钮可定位（字段 → 字段面板并选中；映射 → 映射列表并选中；文件 → 切换文件），失效锚点显示「已失效」徽标与原因、不可点；写评论时可选「关于」= 整个项目 / 当前字段 / 当前映射 / 当前文件；`@` 弹出成员候选；回复、编辑/删除自己的、标记解决/重新打开。收件箱新增 `docs.mention`（立即邮件）与 `docs.comment`（汇总）；从通知进入项目页 `?comment=<id>` 自动打开抽屉并高亮。 |
| 边界与风险 | 权限：读写评论 = 能打开项目（viewer 也可提问）；编辑只限作者；删除限作者或空间 owner/admin；标记解决限作者或能编辑项目的成员；外人 403/404。提及：只通知项目所在空间的活跃成员，其他人静默丢弃（不告诉作者「此人无权」以免探测成员）；作者不被通知；编辑时只通知新增的提及。锚点：写入时校验对象存在；读取时若字段不在当前模板版本/模板已更换/映射或文件已删则 `valid=false` 并给原因，文件版本变化标 `changed`。内容：纯文本 ≤ 4000 字，控制字符剔除，链接不展开；每分钟 60 条限流。三语言 32 条；手机：抽屉全宽、无横向滚动。 |
| 验收 | `tests/integration/test_project_comments.py`（成员名单只含姓名；提及成员 → `docs.mention` 含正确链接、非成员被丢弃、作者不通知；viewer 回复 → 参与者 `docs.comment`；外人 403/404；他人不能编辑、作者可编辑且不重复提及；viewer 不能解决、编辑可解决、默认列表隐藏已解决线程（含回复）、重复解决 409、重开；删字段后锚点 `valid=false, reason=slot_gone` 且保留标签；坏锚点/空正文/回复的回复 400；删除限作者或管理员、回复随线程删除）；浏览器 `ui_e2e_comments.py`（编辑者选中字段评论并 `@` 提及；查看者手机铃铛 → 打开项目并高亮 → 定位 → 回复；编辑者收到 `docs.comment`；删字段后锚点显示已失效且不可点；标记解决后隐藏，勾选显示已解决可见）。 |
| 发布与恢复 | schema v16 一张表；无迁移。回滚：表被忽略。 |

## 2. 接口

| 接口 | 权限 | 说明 |
|---|---|---|
| `GET /api/projects/{pid}/comments?include_resolved=` | 项目可读 | 一级与回复平铺；`anchor.valid/reason/changed` 为读取时判断 |
| `GET /api/projects/{pid}/comment-members` | 项目可读 | 可提及的成员：`user_id`、`name` |
| `POST /api/projects/{pid}/comments` | 项目可读 | `{body, anchor?, mentions?, parent_id?}`；201 |
| `PATCH /api/comments/{cid}` | 作者 | `{body, mentions?}` |
| `DELETE /api/comments/{cid}` | 作者或空间管理员 | 软删除，回复随线程 |
| `POST /api/comments/{cid}/resolve` / `reopen` | 作者或能编辑项目的成员 | 一级评论 |

锚点：`{kind: project}` / `{kind: slot, id, label, template_id, template_version}` / `{kind: mapping, id, label, mapping_rev}` / `{kind: source, id, label, version}` / `{kind: job, id}`。
