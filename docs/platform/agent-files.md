# Agent 个人文件

个人 Agent 可上传、查看解析结果、选择并发送个人文件。文件归稳定 user ID，未分配到任何工作空间；
空间管理员与平台管理员均不因此获得读取权。文件选择不授予模型额外工具权限，正文中的指令只作为不可信输入。

## 支持范围

复用部署组装层注入的 Docs 读取器，不调用外部模型或 OCR。支持 UTF-8（含可选 BOM）的 TXT、MD、CSV（逗号）、
TSV（制表符）；MD 保留源文本，CSV/TSV 保留空白、多行单元格与前导零。拥有完整 PDF 引擎的部署支持可验证的纯文字 PDF。
PDF 含图片、绘图、隐藏文字、注释、表单、链接、附件、图层，或需要修复/解密时拒绝整份文件，不把部分文字当作完整输入。
图片 OCR、Word、Excel 附件尚不受此入口支持，不能根据 Docs 的其他能力推断已支持。

每文件不超过 8 MiB，个人最多 50 项、50 MiB，每日最多 100 次新上传。重复同键请求不新增文件或占用新次数；
同键改名或改变字节返回冲突。解析完整输出 JSON 最多 60,000 字符；最多 200 页、5,000 行、
2,000 表格行、100 列、10,000 单元格，单行/单元格最多 10,000 字符。超限明确拒绝，不截断。
文件与业务资源每次合计最多 5 项、上下文整体最多 60,000 字符（含来源及标题），仍受会话和模型预算约束。
文件尚未发送前的解析不收费；随后模型调用遵循原有明确报价、预留和结算。

扫描沿用实际接纳策略。未配置扫描器时明确显示未配置，不能宣称扫描安全；后续隔离状态同样阻止预览、下载和派发。

## 接口和运行

HTTP 上传、下载使用本人登录会话；上传沿用 CSRF 检查，不接受机器身份或管理员代读。

| 入口 | 行为 |
| --- | --- |
| `GET /api/suite/agent/files/capabilities` | 当前可用格式、大小/配额、真实扫描器状态 |
| `POST /api/suite/agent/files` | multipart `file`，必需 `Idempotency-Key`，接纳后返回个人文件记录 |
| `agent.file.list` | 本人文件分页，`offset`；每页20项及 `next_offset` |
| `agent.file.get` | 当前状态、完整解析预览、不可变 `reference` |
| `agent.file.cancel` / `retry` / `delete` | 取消读取、显式有限重试、删除；沿用注册操作接口和幂等语义 |
| `GET /api/suite/agent/files/{id}/download` | 当前权限与隔离复查；附件下载、禁止内容嗅探、不缓存 |

操作入口为 `/api/suite/ops/{operation}`。`agent.file.*` 不向模型暴露。
报价、运行、持续授权使用 `file_refs: [{file_id, snapshot}]`，不接受客户端正文；与 `context_refs` 分开。
报价取消保留选择，接受运行才清空输入。重新生成不能替换源文件或自动重放写入。

状态为 receiving → queued → parsing → ready，另有 failed/cancelled/deleted。
部署中的持久队列每秒检查，最多4项并发接纳、2项解析；独立子进程最多90秒，Linux内存上限768 MiB，
关闭/取消时终止解析及子进程。解析租约超时可重启接管，总尝试最多3次，不无限重试。
输入引用、来源证明和报价在同一既有接纳事务内固定；派发、工具确认、历史、SSE、报告/导出都复查当前来源。

## 保留、删除和兼容

未被消息引用的文件24小时后失效：即使清理线程尚未运行，也不能下载、选择或完成解析。
已引用的文件保留至本人删除；删除会话后，失去引用的文件恢复通常过期清理。
删除清除原始字节、解析文本和用户消息中保存的文件快照；保留来源证明，使相关历史生成块保守隐藏、待运行步骤停止。
此前合法写入其他业务应用的独立产物按目标访问/保留政策管理，不伪装成全部回滚。

`Store` 是唯一迁移与持久化入口。新增 `agent_files` 将有严格配额的字节存为内联 BLOB，清理同事务置空；
不产生共享 blob 目录的孤儿文件。元数据查询不加载原字节。已删除且无引用的幂等墓碑30日后清除。
SQLite/WAL及备份依照既有保留机制管理，这不是即时物理擦除，也无法撤回之前已合法下载的副本。

账户删除宽限期仍可恢复；最终删除由现有 `agent_records.erase` 和数据库触发器共同覆盖。
旧账户服务即使不知道新表，完成用户删除时也会清除新文件。迁移可重复且只新增；旧 Agent 不理解的
个人文件来源带 `workspace_id: null`，按既有来源检查保守隐藏/停止，而不是把它当作无约束私人文本继续发送。

## 验证与上线证据

Docs 格式测试和组合工厂集成使用真实 TXT/CSV/MD/PDF 字节与实际解析子进程；权限、删除、撤权、隔离、
报价绑定、并发幂等、租约恢复和账户兼容在隔离 Store 验证。浏览器使用合成文件、真实身份与应用服务。
模型/付款的测试传输不作为真实 DeepSeek 或 Stripe 验收。准确测试、CI和部署状态见 `docs/agent-work/EVIDENCE.md`。
