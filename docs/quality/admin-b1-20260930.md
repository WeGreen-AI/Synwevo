## 现场和范围

隔离工作区 `codex/admin-platform` 从既有 B1-2 分支接续，在 `127590c` 合并本地主分支 `01082ba`。主检出另有 API 专项未提交工作，本批未修改或混入。远端 main 之后本地主分支还包含此前已提交工作，本批不能将它们冒充为本次新增。

验证使用 Python3.12.6、按锁安装的依赖和当前工作区包；Node23.6.1（生产构建使用Node22）。所有身份、密码和内容为隔离fixture。没有读取生产用户内容、外发真实邮件或更改真实管理员权限。

## 兼容与接续

新日志类型 `platform_grant_revoked` 要求恢复工具支持新版读取器，旧读取器会拒绝；禁止删记录以通过旧工具。重放导致原有可用最高管理员归零时拒绝恢复；开始就未初始化的备份仍允许恢复。无日志恢复尚缺持久安全核对门禁，不能据“旧会话已结束”判断旧人类授权安全。

当前批次验收后继续：初始化事务/短时恢复证明、无口令严格重认证、接任验证与强因素保护、无日志恢复门禁；随后推进配置版本与真实执行点、组织/业务和运维治理。第一批完成不代表整体目标完成。
