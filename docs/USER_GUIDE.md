# 使用说明

工作台的核心是左右对应：**左侧是来源文件**，**右侧是目标模板**。建立的对应关系（映射）和样本规则会保存在项目里，下一批同结构的文件可以直接复用。

## 第 1 步：新建项目，上传来源文件

1. 首页点击「＋ 新建项目」。
2. 把文件拖到左侧「来源文件」区，或点击上传（可多选）。支持 XLSX/XLS/CSV/ODS、DOCX/DOC/ODT/RTF、PDF、PNG/JPEG 等图片、PPTX/PPT/ODP、TXT/Markdown/HTML。
3. 每个文件显示真实状态：解析中 / 可用 / 需 OCR / 错误（附原因）。可拖动调整顺序、移除文件、设为「代表文件」（用来建立规则的样例）。
4. 左侧工具栏的「查找」会在整个文件中搜索（包括尚未显示的行、所有页面、页眉页脚），回车跳到下一个结果。
5. CSV 乱码或分列不对：点击左侧工具栏「CSV 设置」改编码与分隔符。扫描件/图片：点击「OCR 识别」（在本机识别，不上传）。

## 第 2 步：设置目标模板

点击右侧「设置模板」，三种方式：

* **上传已有文件**：DOCX、XLSX、PDF、PPTX（旧格式会转换并提示）。原始模板保持不变，字段保存在工作副本中。
* **新建文档型模板**：像写文档一样编辑，点击「＋ 插入字段」放入待填字段；表格中把光标放在某一行，点击「设为重复明细行」；可设置纸张、页边距、页眉页脚、图片、分页符。
* **新建表格型模板**：编辑单元格与样式、合并单元格，选中单元格后「设为字段单元格 / 固定区域 / 重复明细行」。

### 把已有内容设为待填区域（挖空）

在右侧模板上：

* DOCX / PPTX：用鼠标**划选文字**（可以跨不同格式的文字）；点单元格选择单元格；表格行左侧的「≡」选择整行（用于重复明细行）；Shift + 点击另一个单元格选择区域。按住 Alt（Option）点击可以放置插入光标。
* XLSX：拖动框选单元格（单个 = 字段单元格，多格 = 固定区域，一行多格还可设为重复明细行）。
* PDF：在页面上**拖动画框**，或点击某个词。表单型 PDF 在顶部列出已有表单字段。

然后点击底部「✎ 设为待填区域」，填写字段名称。默认「替换选中内容」，也可以「保留原文，在指定位置插入」。字段名与已有字段相同时，可以选择共享同一个数据绑定。

字段可以在右侧「字段」面板中修改：名称、必填、数据类型、为空时的默认值、字段格式、零条明细时的处理、表头是否跨页重复、PDF 字号与对齐等；删除字段会恢复模板原内容，并同时删除相关映射（会先提示）。所有修改都可「撤销 / 重做」。

## 第 3 步：定义样本（每份输出对应什么数据）

点击步骤条「定义样本」：

| 模式 | 一份输出 = | 例子 |
|---|---|---|
| 每行一份 | 表格中的一条有效数据行 | 100 行客户 → 100 份合同 |
| 每文件一份 | 一个来源文件 | 20 份检测表 → 20 份报告 |
| 每组一份 | 按选定字段（如订单号）分成的一组 | 100 条明细属于 15 个订单 → 15 份 |

需要指定工作表、表头行、数据范围、是否排除空白行、过滤条件；分组模式还要选择分组字段、组内排序，以及多个文件是否跨文件合并分组。右侧会实时显示识别出的样本数量、排除的空白行数量和样本清单。

在左侧表格中框选多行后，底部会出现「选中区域的含义…」：明确这些行是「每行一份」还是「作为同一份文档的明细」，并提前显示将生成的份数。

## 第 4 步：建立映射

1. 左侧选中来源数据（单元格、区域、文字、PDF 框选）。
2. 右侧点击一个字段（字段带有名称标签）。
3. 点击底部「⇄ 建立映射」，在对话框中确认来源含义：
   * 「随样本变化：每条样本的某列」——每份输出读取当前样本对应的值（每行/每组模式的默认）；
   * 「固定单元格」——同一文件中所有样本使用同一个值；
   * 「明细表」——多行数据写入重复明细行，按列名对应（列顺序不同不会错位），未匹配的列可以手动选择。
4. 可添加值转换（去空格、日期显示、小数位、前后缀、默认值、对照替换等）；分组模式下，组内多个不同值时必须选择取值规则，否则报冲突。
5. 需要把某个映射改到另一个字段时：在右侧点选新字段，再点映射列表中的「改绑」。
6. 一个来源可以写入多个字段；同一个字段只能有一个映射——需要多个来源时选择「拼接 / 换行 / 求和」合并。

每个映射有编号和颜色，左右两侧对应位置都会高亮并用连线相连（可在顶部关闭连线）。点击映射列表中的某项会同时滚动定位两侧。列表显示当前来源文件中的实际取值；某个文件取不到值时会标红。

「校验」面板：逐个来源文件检查每个映射能否定位；有问题的文件可以「在此文件中重新定位」（为该文件单独保存定位），扫描件的低置信度识别值在这里确认或修正。

## 第 5 步：预览与生成

* 「👁 预览」：用与批量生成**完全相同的规则**生成真实文件并显示，可上一条 / 下一条 / 按样本标识查找，问题列表可点击定位到映射，也可以下载该预览文件。
* 「▶ 生成」：显示输入文件数、识别样本数、有效样本数、错误和警告数、预计输出文件数；选择输出格式（不可用的格式会说明原因与替代方案）、文件命名（可用字段组合，如 `{订单号}_{客户}`）、遇到错误时「不开始」或「跳过错误样本」。
* 任务页面显示真实进度、成功/失败/跳过/取消数量，可取消、重试失败项，下载单个文件、ZIP 或结果清单（CSV，含失败原因）。刷新页面或服务重启后任务状态仍在；手机上也可以查看任务并下载。

## 复用到下一批文件

同一项目中移除旧来源、上传新的一批同结构文件即可再次生成；模板、样本规则、映射都会保留。模板也可以在「模板库」中复制给其他项目使用。
